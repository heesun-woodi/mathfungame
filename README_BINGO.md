# 🎮 mathfungame - 빙고 게임 모드

수학 문제를 풀면서 동물 그림을 맞추는 빙고 게임!

## 🚀 빠른 시작

### 1. 배포 확인
- Vercel 대시보드: https://vercel.com/
- 프로젝트: `mathfungame`
- 배포 상태 확인 (Building → Ready)

### 2. DB 마이그레이션
배포 완료 후, 아래 URL에 한 번 접속:
```
https://mathfungame.vercel.app/api/migrate
```

### 3. 게임 시작
```
https://mathfungame.vercel.app
```

## 🎯 게임 방법

### 1단계: 플레이어 선택
- 기존 플레이어 선택 또는 새 플레이어 생성

### 2단계: 빙고 게임 플레이
1. **5×5 빙고 보드** 표시 (모두 잠금 상태)
2. **칸 클릭** → 수학 문제 출제
3. **정답 입력** → 맞으면 칸 오픈 ✅
4. **그림 공개** → 열린 칸 뒤에 동물 그림 드러남
5. **5줄 완성** → 가로/세로/대각선 5줄 완성 시 다음 단계

### 3단계: 동물 맞추기
1. **그림 전체 공개**
2. **동물 이름 입력**
3. **힌트 사용** (최대 3개)
   - 힌트 1: 첫 글자 초성
   - 힌트 2: 글자 수
   - 힌트 3: 영어 이름
4. **정답 확인** → 빙고 완료! 🎉

### 4단계: 선택
- **레벨 올리기**: 다음 레벨에서 새 빙고 시작
- **같은 레벨 더 하기**: 현재 레벨 유지하고 새 빙고
- **그만하기**: 홈으로 돌아가기

## ⚙️ 설정

### 일일 목표 빙고 수
- 1빙고 (기본)
- 2빙고
- 3빙고
- 무제한

### 레벨
- Lv.1 ~ Lv.10
- 레벨이 높을수록 어려운 문제

### 연산자
- 덧셈 (+)
- 뺄셈 (-)
- 곱셈 (×)
- 나눗셈 (÷)
- 원하는 연산만 선택 가능
